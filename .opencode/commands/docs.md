description: Update project documentation after a change
---

Review the changes made in this session and update the affected files under `docs/` (README.md, architecture.md, development.md, conventions.md, screens/). If a session touched or described a screen ("fenêtre"), create or update its dedicated file `docs/screens/<id>.md` and register it in `docs/screens/README.md` index. Keep the documentation concise, in French, and consistent with the existing style. Do not document minor implementation details — only what affects structure, commands, or conventions.
